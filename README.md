# CORVEX SPORT

MVP لنظام إدخال وطباعة طلبات متجر ملابس.

## الوظائف الحالية
- Login متعدد المستخدمين.
- إضافة طلب يدوي.
- لصق طلب كامل وتحليله تلقائياً محلياً بدون API مدفوع.
- كود طلب تلقائي متسلسل.
- بحث بالكود / الهاتف / الاسم.
- قائمة الطلبات غير المطبوعة.
- دفعات طباعة محفوظة.
- 8 بوالص على ورقة A4.
- إعادة طباعة دفعة أو صفحة من 8 طلبات أو بوليصة منفردة.
- كشف طلبات قابل للطباعة.
- تنزيل CSV متوافق مع Excel كبداية.

## النشر على Cloudflare Pages + D1
1. أنشئ D1 database باسم `corvex-sport-db`.
2. نفذ ملف `schema.sql` على قاعدة البيانات.
3. حدّث `database_id` داخل `wrangler.toml` أو اربط D1 من إعدادات Pages باسم binding: `DB`.
4. ارفع المشروع إلى GitHub ثم Cloudflare Pages، ومجلد الإخراج هو `public`.
5. أول مستخدم Admin يتم إنشاؤه من endpoint خاص بالتهيئة `/api/setup` إذا لم يوجد أي مستخدم بعد.

## ملاحظة
هذه النسخة مقصودة لتكون بسيطة: لا حالات توصيل، لا مخزون، لا ألوان/مقاسات كحقول مستقلة حتى الآن.


## V11 — نتائج التوصيل والربحية
أضيفت حالات: قيد التنفيذ، تم التسليم، تم التسليم وتعديل قيمة، رفض مع دفع أجور،
رفض مع عدم دفع أجور، واستلام جزئي. كما أضيفت حقول أجور التوصيل، الكاش المستلم،
تكلفة البضاعة، وعدد القطع المسلمة/المرتجعة. النظام يقوم بترقية جدول orders تلقائياً
عند أول طلب API بعد تسجيل الدخول، لذلك لا تحتاج لتشغيل migration يدوياً.
